## Decisions in this build (say if you want them changed)

- Defaults reproduce the pre-B2 keys exactly; the hotkey review changes them in `InputCatalog`.
- CONTROLS sits in the pause menu's **session** stack (above END SESSION), not the review stack: the review stack
  stays at ≤ 9 rows so CLASHES (round C) still fits at 1280 × 720.
- Three keys per action (the tour's next stop already used three: → / PgDn / LMB).
- Keymap files are JSON (`*.json`, format `bimgo-keymap`), the whole map; import = the defaults plus the file.
