| Off grid | **Nearest, any distance**; host grids, the links' when the host has none |
| Minimap | **Lines + edge labels** |
| Shown in | **Clash card + report**; plus (Gavin's own option) **an option to include it in comments / BCF, off by default** |
| Line style default | **Solid by default** (dash-dot as the option) |
| Group names | **"Near C-4" / "Near C-4 : Level 2"** |
