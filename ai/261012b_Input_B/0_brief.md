## Gavin's direction for build B (2026-10-12)

- Assume an **Xbox-style controller**: left stick, right stick, D-pad, Start / Select (Back), two shoulder buttons a
  side (LB / LT, RB / RT), four face buttons.
- **Combinations** where they suit, e.g. **shoulder + D-pad**, to expand what the pad can do.
- ~~Look on the left stick, move on the right~~ → corrected the same day: **move left, look right**; **click the right stick for the gun wheel**.
- The controller is **secondary support**: don't make the mouse / keyboard setup worse for its sake.

## Earlier answers that apply

- Gamepad rebindable in the same action map, its own column in CONTROLS.
- Menus: a stick drives the cursor, A clicks, B goes back (the Esc chain), Start pauses.
- Tuning: look sensitivity, invert Y, dead zone, trigger threshold; the first connected controller.
- Gun wheel: hold MMB, steer, release to pick; release in the centre cancels; keyboard key unbound by default.
