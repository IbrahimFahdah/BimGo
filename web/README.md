# BimGo Web

BimGo for the browser: a TypeScript + WebGL2 port of the BimGo walkthrough app, hosted on GitHub Pages. The plan, and the notes for each phase, are in `ai/261007_Web/`.

```
npm install
npm run dev      # http://localhost:5173/BimGo/
npm test
npm run lint
npm run build    # static site in dist/
```

`.bimgo` files are opened from your disk and never uploaded.
